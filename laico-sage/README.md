# قالب وردپرس لایکو دیزاین (Laico Design — Roots Sage WordPress Theme)

نسخهٔ کامل و وفادار به جزئیات قالب معماری داخلی و سیستم آشپزخانه **لایکو دیزاین**، پیاده‌سازی‌شده بر پایهٔ فریم‌ورک مدرن **Roots Sage (Acorn + Blade + Vite)**.

---

## قابلیت‌های کلیدی پیاده‌سازی‌شده

### ۱. پنل تنظیمات جامع قالب (`پنل تنظیمات لایکو` در پیشخوان وردپرس)
دارای ۶ تب تخصصی با رابط کاربری راست‌به‌چپ سرمه‌ای/طلایی:
- **عمومی و برندینگ (`general`):** مدیریت لوگو، فاوآیکون، زبان پیش‌فرض (`FA` / `EN`)، سوییچر دوزبانه هدر، تلفن‌ها، ایمیل، آدرس، ساعات کاری، مختصات نقشه، شبکه‌های اجتماعی، کپی‌رایت فوتر + **ابزار راه‌اندازی یک‌کلیکی برگه‌های اصلی و محتوای نمونه**.
- **بخش‌های قالب (`sections`):** روشن/خاموش کردن تک‌تک بخش‌های صفحه اصلی (مجموعه‌ها، پروژه‌های منتخب، استودیو و آمار، مرام ساخت، مجله، فرم مشاوره)، ویرایش متن‌های پیش‌فرض هیرو و شمارنده‌های آماری.
- **بهینه‌سازی و سرعت (`optimization`):** پیش‌بارگذاری فونت‌های `Vazirmatn`، پیش‌بارگذاری هوشمند تصویر شاخص هیرو (`LCP Preload` با `fetchpriority="high"`)، اسکریپت ضدپرش زبان و انیمیشن (`Zero-FOUC`)، بارگذاری `defer` اسکریپت‌ها، حذف ایموجی‌ها، oEmbed، Dashicons مهمان، `jquery-migrate`، مسدودسازی `XML-RPC` و پیش‌واکشی هوشمند لینک‌ها (`Hover Prefetch`).
- **تنظیمات سئو (`seo`):** موتور سئوی داخلی با تشخیص خودکار Yoast / RankMath، تولید تگ‌های Canonical، Open Graph، Twitter Card، اسکیماهای JSON-LD (`ArchitectureFirm`، `WebSite`، `Article`، `CreativeWork`)، متاباکس سئو در برگه‌ها/نوشته‌ها/پروژه‌ها، و **ریدایرکت ۳۰۱ خودکار آدرس‌های قدیمی `.html`** به پیوندهای یکتای وردپرس.
- **فرم‌ها و اعلان‌ها (`forms`):** تنظیم ایمیل دریافت‌کننده، اتصال به ربات تلگرام، محدودیت نرخ ارسال (`Rate Limit`)، تله ضدربات (`Honeypot`) و شخصی‌سازی پیام موفقیت دوزبانه.
- **نصب بروزرسانی از طریق پچ (`patch`):** سامانهٔ امن و اتمیک نصب پچ‌های بروزرسانی قالب:
  - پشتیبانی هم‌زمان از بسته‌های استاندارد **`.zip` حاوی `patch.json`** و فایل‌های **`.patch` / `.diff` استاندارد Git Unified Diff** (موتور تفاضلی خالص PHP بدون نیاز به `exec`).
  - بررسی مجوزهای `update_themes`، `DISALLOW_FILE_MODS`، مسدودسازی کامل Path Traversal و Symlink، و صحت‌سنجی چک‌سام **SHA-256**.
  - پشتیبانی از امضای دیجیتال **Ed25519 (Sodium)** و **HMAC-SHA256**.
  - بررسی سینتکس فایل‌های PHP در حافظه (`token_get_all(..., TOKEN_PARSE)`) پیش از نوشتن روی دیسک برای جلوگیری کامل از خطای سفید (WSOD).
  - پیش‌نمایش آزمایشی (**Dry-Run**)، تهیه **نسخه پشتیبان خودکار محافظت‌شده** در `wp-content/uploads/laico-patches/backups/`، جایگزینی اتمیک فایل‌ها، پاک‌سازی کش Blade و OPcache، و **بازگردانی تک‌کلیکی (Rollback)**.

### ۲. بخش اختصاصی پروژه‌ها (`laico_project`)
- پست‌تایپ سفارشی `پروژه‌ها` به همراه ۳ طبقه‌بندی دوزبانه: `دسته‌بندی (مسکونی/تجاری)`، `نوع فضا` و `موقعیت / شهر`.
- متاباکس‌های کامل تک‌صفحه پروژه: **کارفرما**، **سال شمسی/میلادی**، **مدت زمان پروژه**، **مکان**، **متراژ (مترمربع)**، **انتخابگر چندتایی گالری تصاویر با لایت‌باکس**، **انتخابگر اسکیس‌های پروژه (بخش «اسکیس‌های پروژه» با لایت‌باکس جدا)**، **ویدیوی پروژه و پوستر**، جایگاه در موزاییک صفحه اصلی و فیلدهای انگلیسی دوزبانه.
- **اسکیس‌های آماده همراه قالب:** مجموعه‌های داخل `resources/sketches/<slug>/` (فعلاً «کافه» با ۳۲ برگ) در همان متاباکس با دکمهٔ «افزودن این مجموعه به اسکیس‌های پروژه» به کتابخانهٔ رسانه کپی و به فهرست اسکیس‌های پروژه اضافه می‌شوند؛ پس از آن پروژه را «به‌روزرسانی» کنید. بخش اسکیس فقط در پروژه‌هایی دیده می‌شود که اسکیس دارند؛ برگه‌های عمودی در شبکهٔ چهارستونه و مجموعه‌های پرتعداد با دکمهٔ «نمایش همه» نمایش داده می‌شوند.
- فیلتر زنده، جستجوی آنی و صفحه‌بندی در آرشیو پروژه‌ها (`/projects/`).

### ۳. مجله از نوشته‌های وردپرس (`post`)
- صفحه مجله (`/journal/`) و تک‌صفحه مقالات مستقیماً از **نوشته‌های بومی وردپرس (`Posts`)** تغذیه می‌شوند.
- تبدیل خودکار تاریخ به شمسی (جلالی) در کنار تاریخ میلادی، محاسبه خودکار زمان مطالعه، متاباکس نسخه انگلیسی و نمایش مقالات مرتبط.

### ۴. بارگذاری تصاویر هیرو از «تصویر شاخص هر برگه»
- در هر ۶ صفحه اصلی (**صفحه اصلی، خدمات، پروژه‌ها، مجله، درباره ما، تماس با ما**) و زیرصفحات، تصویر تمام‌صفحهٔ بخش هیرو مستقیماً از **تصویر شاخص برگه (`Featured Image`)** به همراه `srcset` واکنش‌گرا و `alt` خوانده می‌شود (و در صورت عدم انتخاب تصویر شاخص، به تصویر پیش‌فرض قالب برمی‌گردد).

### ۵. بخش ارسالی‌های فرم مشاوره (`ارسالی‌های فرم`)
- ذخیره تمامی فرم‌های مشاوره در جدول اختصاصی پایگاه‌داده (`{$wpdb->prefix}laico_submissions`) از طریق REST API (`/wp-json/laico/v1/submissions`) به همراه پشتیبان خودکار `admin-ajax.php`.
- جدول مدیریت استاندارد `WP_List_Table` در پیشخوان وردپرس با شمارنده پیام‌های خوانده‌نشده در منو، فیلتر وضعیت (`جدید`، `بررسی‌شده`، `تماس‌گرفته‌شده`، `بایگانی`)، جستجو، صفحه جزئیات و ثبت یادداشت داخلی مدیر، لینک مستقیم تماس/واتس‌اپ و **خروجی اکسل CSV سازگار با فارسی (UTF-8 BOM)**.

## نصب و راه‌اندازی در وردپرس

1. پوشهٔ `laico-sage` را در مسیر `wp-content/themes/laico-sage` قرار دهید.
2. وابستگی‌های Composer (فریم‌ورک Roots Acorn) را در پوشهٔ قالب نصب کنید (یا افزونهٔ رسمی **Acorn** را در وردپرس فعال نمایید):
   ```bash
   cd wp-content/themes/laico-sage
   composer install --no-dev --optimize-autoloader
   ```
   *(فایل‌های کامپایل‌شدهٔ فرانت‌اند از پیش در `public/bundle/` قرار دارند و نیازی به نصب Node.js روی سرور تولید نیست.)*
3. از منوی **نمایش ← پوسته‌ها**، قالب **Laico Design (Sage)** را فعال کنید.
4. به منوی **تنظیمات لایکو** بروید و در پایین تب اول روی دکمهٔ **«اجرای درون‌ریزی هوشمند محتوای اولیه»** کلیک کنید تا برگه‌های اصلی، تصاویر شاخص هیرو، منوها، پروژه‌ها و مقالات نمونه به‌صورت خودکار ایجاد شوند.

## ساخت مجموعهٔ اسکیس از فایل PDF (`tools/sketches_from_pdf.py`)

برگ‌های یک یا چند فایل PDF (نقشه، دیتیل، پرسپکتیو) با اسکریپت `tools/sketches_from_pdf.py` در ریشهٔ مخزن به یک «مجموعهٔ اسکیس» تبدیل می‌شوند: برای هر برگ یک تصویر کامل WebP (لایت‌باکس و بزرگ‌نمایی) و یک تصویر بندانگشتی آماده (شبکهٔ صفحه)، به‌همراه فایل `set.json` که ترتیب، ابعاد و زیرنویس فارسی/انگلیسی برگ‌ها را نگه می‌دارد.

1. یک فایل مشخصات مثل `tools/sketch-specs/cafe.json` بسازید (نامک مجموعه، عنوان، و برای هر برگ: نام فایل PDF، شمارهٔ صفحه، نام کوتاه لاتین و زیرنویس `fa` / `en`).
2. اسکریپت را اجرا کنید (نیازمند `pip install pymupdf pillow`):
   ```bash
   python3 tools/sketches_from_pdf.py tools/sketch-specs/cafe.json \
     --pdf-dir /path/to/pdf-files \
     --out assets/images/sketches/cafe \
     --out laico-sage/resources/sketches/cafe \
     --manifest laico-sage/resources/sketches/cafe
   ```
3. قالب هر پوشهٔ `resources/sketches/<slug>/` را که `set.json` معتبر داشته باشد خودکار در کادر «اسکیس‌های آماده همراه قالب» ویرایش پروژه نشان می‌دهد؛ نیازی به `npm run build` نیست. (در سایت استاتیک، بخش اسکیس `project-cafe-amol.html` را الگو بگیرید.)

نکته‌ها: هر برگ فقط یک بار وارد کتابخانهٔ رسانه می‌شود (کلید `_laico_source_asset`) و افزودن دوبارهٔ مجموعه چیزی را تکراری نمی‌کند؛ زیرنویس هر برگ در فیلد «زیرنویس» رسانه به‌صورت «فارسی | English» ذخیره می‌شود و همان‌جا قابل ویرایش است؛ با حذف یک برگ از کتابخانهٔ رسانه، دفعهٔ بعد که مجموعه اضافه شود آن برگ دوباره ساخته می‌شود.

## ساخت بستهٔ بروزرسانی پچ (`bin/make-patch.py`)

برای ساخت بستهٔ `.zip` استاندارد پچ جهت بارگذاری در تب **بروزرسانی از طریق پچ**:

```bash
python3 laico-sage/bin/make-patch.py \
  --id patch-1.4.1 \
  --min-version 1.4.0 \
  --to-version 1.4.1 \
  --description "بهبود بخش پروژه‌ها و بهینه‌سازی استایل‌ها" \
  --files resources/views/front-page.blade.php app/Support/Hero.php \
  --hmac-secret "YOUR_SHARED_SECRET" \
  --output laico-patch-1.4.1.zip
```
