# رُزآ — سند طراحی و هویت بصری

> فروشگاه آنلاین لوازم آرایشی و کالای وارداتی (آرایشی، مراقبت پوست، عطر، لوازم برقی، پوشاک و مکمل)
> با پالت **رُز‑شنی‑فیروزه‌ای**، رابط فارسی RTL، بدون build و بدون وابستگی.
> نسخهٔ ۱٫۰٫۰ · آبان ۱۴۰۴

## ۲. بررسی هویت بصری ۱۰ فروشگاه برتر لوازم آرایشی ایران

مبنای این جدول: بازدید صفحهٔ اصلی و دسته‌بندی‌های اصلی این فروشگاه‌ها (آبان ۱۴۰۴) و
جمع‌بندی کیفی از پالت، تایپوگرافی، چگالی چیدمان و نشانه‌های اعتماد. رنگ‌ها **تقریبی**
و توصیفی‌اند، نه نمونه‌برداری دقیق.

| # | فروشگاه | حس بصری و پالت | الگوهای رابط | درسی که گرفتیم |
| --- | --- | --- | --- | --- |
| ۱ | **خانومی** | صورتی تند/ماژنتا + سفید، فضای شلوغ و جشنواره‌ای | مگامنوی پرجزئیات، کاروسل بنر، «جعبهٔ صورتی» با تایمر روزانه، شبکهٔ ۵–۶ ستونه، درصد تخفیف درشت | رنگ برند می‌تواند قوی باشد، اما چگالی بالا حس «انبار» می‌دهد؛ ما صورتی را آرام‌تر و انتخابی به‌کار می‌بریم |
| ۲ | **موتن‌رو** | سرخابی/بنفش نئونی روی بنرهای تیره، حس کمپین شبانه | بنرهای تیره با نور نئون، تایمر شمارش معکوس، برچسب «٪۷۰»، پیل‌های گرد | کنتراست تیره/نئون خوب می‌فروشد؛ نسخهٔ ما همان کنتراست را با فیروزه‌ای عمیق و بدون شلوغی اجرا می‌کند |

| ۵ | **عسل بانو** | حس گرم و سنتی، تأکید بر «کالای اصل» | برندهای متنوع، تخفیف‌های ساده، اطلاعات تماس پررنگ | ادعای اصالت بدون مدرک قابل بررسی، اعتماد نمی‌سازد → ما «کارت اصالت + کد رهگیری + سند» را به رابط آوردیم |

| ۷ | **دیجی‌کالا (دستهٔ زیبایی)** | قرمز برند + سفید، چگالی بسیار بالا، جدول مشخصات | فروشندهٔ متعدد، امتیاز و نظر، فیلترهای قدرتمند، تحویل سریع | فیلتر و شفافیت فروشنده ارزشمند است؛ ما نسخهٔ سبک و خوانا را در فیلترهای فروشگاه آوردیم |
| ۸ | **سرمه شاپ** | تیره/پلوم با عکس‌های دراماتیک آرایش | بنرهای احساسی، دسته‌بندی آرایشی | عکاسی احساسی، فروش آرایشی را بالا می‌برد؛ قهرمان صفحهٔ ما یک عکس تحریری رز/فیروزه است |
| ۹ | **بیوتی کد** | پالت ملایم، تمرکز بر برند و اصالت | لیست برند، توضیح محصول، نظرات | صفحهٔ محصول باید «مدرک» داشته باشد، نه فقط توصیف → تب مشخصات/اصالت در PDP |
| ۱۰ | **زز زاگرس** | حس واردات و عمده‌فروشی، چیدمان ساده و شلوغ | دسته‌بندی گسترده، قیمت درشت | تجربهٔ واردات بدون «شفافیت قیمت» ناقص است → نمایش قیمت خارجی و تفکیک کارمزد |

Also considered: **روبان** و **مدیسه** (تنوع برند + تخفیف منظم) — همان الگو، بدون ایدهٔ تازهٔ بصری.

### ۲٫۱ پنج الگوی مشترک بازار

1. **صورتی/قرمز به‌عنوان رنگ اصلی** و سفید به‌عنوان بوم؛ رنگ تیره فقط در بنر کمپین.
2. **تخفیف به‌عنوان عنصر هویتی**: برچسب درصد، تایمر، «حراج روزانه».
3. **چگالی بالا**: ۵–۶ ستون کارت، مگامنوی چندستونه، بنرهای متعدد.
4. **عکس محصول روی زمینهٔ روشن**، اغلب بدون سایه یا استایل تحریری.
5. **اعتماد از طریق لوگوها و نشان‌ها** (نماد اعتماد، «اصالت کالا»، شمارهٔ تماس).

### ۲٫۲ چهار شکاف که رُزآ پر می‌کند

| شکاف | پاسخ در طراحی |
| --- | --- |
| «اصل بودن» ادعا می‌شود، قابل بررسی نیست | بلوک «مسیر کالا» در صفحهٔ محصول + صفحهٔ راهنمای اصالت با سه سند |
| قیمت واقعی واردات پنهان است | مقایسهٔ قیمت خارجی در PDP + تفکیک کالا/ارسال/کارمزد |
| کالای موجود در ایران نیست، راهی هم نیست | جست‌وجوی جهانی با تبدیل ارز و ثبت سفارش واردات |
| همه چیز با تخفیف فریاد زده می‌شود | ریتم آرام، فضای سفید، یک CTA اصلی در هر نما |

## ۳. پالت رُز‑شنی‑فیروزه‌ای

| نقش | توکن | مقدار | کاربرد |
| --- | --- | --- | --- |

| بوم گرم | `--sand-1` | `#F6E4DE` | بخش‌های تأکیدی، کارت دسته‌بندی |

| **فیروزه‌ای اصلی** | `--teal-1` | `#1E9E96` | لینک زنده، اسپینر، سوئیچ فعال |
| فیروزه‌ای عمیق | `--teal-2` | `#0F746E` | CTA واردات، آیکون اعتماد |
| فیروزه‌ای تیره | `--teal-3` | `#0A5752` | نوار اعلان، گرادیان پنل تیره |

قواعد استفاده:

- **رز می‌فروشد، فیروزه اعتماد می‌سازد.** هر CTA خرید رز است؛ هر چیزی که به «اصالت، ترخیص،
  جست‌وجوی خارجی» مربوط است فیروزه‌ای.
- تیره‌ها فقط دو جا: نوار اعلان + پنل جست‌وجوی جهانی و مقایسهٔ قیمت.
- روی زمینهٔ رز روشن هرگز متن سفید نمی‌گذاریم (کنتراست کافی نیست)؛ متن `--ink`.
- تأکید گرادیانی فقط برای یک عبارت در هیرو (`em` با گرادیان رز→فیروزه).

## ۴. تایپوگرافی

| نقش | فونت | وزن | اندازه |
| --- | --- | --- | --- |
| تیتر هیرو | Vazirmatn | ۷۰۰ | `clamp(2.35rem, 5.2vw, 4.15rem)` / line-height 1.18 |
| تیتر بخش | Vazirmatn | ۷۰۰ | `clamp(1.6rem, 2.9vw, 2.5rem)` |
| متن | Vazirmatn | ۳۰۰–۴۰۰ | ۱۶px / line-height 1.8 |
| نام برند لاتین | Outfit | ۴۰۰ | ۰٫۶۶rem با letter-spacing ۰٫۱۶em |
| اعداد و کدها | Outfit / tabular-nums | ۴۰۰ | — |

- هیچ letter-spacing روی فارسی اعمال نمی‌شود (اتصال حروف)؛ فقط لاتین فاصله‌گذاری دارد.
- اعداد رابط با `toLocaleString('fa-IR')` به فارسی تبدیل می‌شوند؛ اعداد ارزی لاتین می‌مانند
  تا با `$42` گیج نشوند.
- هفت فایل `woff2` محلی با `font-display: swap` + `preload` دو وزن اصلی.

## ۵. چیدمان، کامپوننت و حرکت

- **شبکه:** `--max: 1280px`، گاتر `clamp(18px, 4vw, 48px)`، کارت‌ها ۴ ستون → ۳ → ۲ → ۱.
- **هدر:** نوار اعلان فیروزه‌ای + هدر شیشه‌ای چسبان (blur)، مگامنوی دو ستونه با یک پنل تبلیغ.
- **هیرو:** دو ستون (متن/عکس)، فرم جست‌وجو با دو حالت «در رُزآ» و «در سایت‌های خارجی»،
  کارت شناور «۹۰+ برند · ۱۲ کشور».
- **کارت محصول:** تصویر ۴:۵، برند لاتین، امتیاز، قیمت + درصد تخفیف، دکمهٔ جمع‌کردن گرد.
- **کشوی سبد:** از سمت راست (RTL)، نوار پیشرفت ارسال رایگان، جمع کالا، پرداخت.
- **حرکت:** ورود تدریجی بخش‌ها (IntersectionObserver، ۲۰px، ۰٫۸s، `ease-out-expo`)،
  زوم آرام تصویر در هاور، مارکی برندها. همه با `prefers-reduced-motion` خاموش می‌شود.
- **دسترس‌پذیری:** یک `h1` در هر صفحه، skip link، فوکوس مرئی، بستن با `Esc`،
  `aria-expanded` روی آکاردئون‌ها، `aria-live` روی نتایج، کنتراست متن ≥ ۴٫۵:۱.

### ۶٫۲ اتصال به سرویس واقعی

در `js/global-search.js` یک نقطهٔ اتصال گذاشته شده است:

```js
var SEARCH_ENDPOINT = ""; // مثلاً "/api/global-search"
```

اگر مقدار بگیرد، سرویس باید `GET /api/global-search?q=...` را بپذیرد و آرایه‌ای با همین
ساختار برگرداند:

```json
[{
  "id": "g-1",
  "title": "Vitamin C 15% Brightening Serum",
  "brand": "SERA Nº7",
  "source": "sephora",
  "price": 42,
  "rating": 4.8,
  "reviews": 2140,
  "img": "https://cdn…/serum.jpg",
  "shipDays": "۹–۱۲",
  "cat": "skincare"
}]
```

نمونهٔ لایهٔ واسط (Cloudflare Worker / Node) که کلید API را پنهان می‌کند:

```js
// GET /api/global-search?q=vitamin+c
export default {
  async fetch(req) {
    const q = new URL(req.url).searchParams.get("q") ?? "";
    const r = await fetch(
      `https://serpapi.com/search.json?engine=google_shopping&q=${encodeURIComponent(q)}&api_key=${env.SERPAPI_KEY}`,
      { cf: { cacheTtl: 900 } }
    );
    const data = await r.json();
    const items = (data.shopping_results ?? []).slice(0, 20).map((x, i) => ({
      id: "live-" + i,
      title: x.title,
      brand: x.source ?? "—",
      source: "amazon",          // یا نگاشت دامنهٔ x.link
      price: Number(x.extracted_price ?? 0),
      rating: Number(x.rating ?? 0),
      reviews: Number(x.reviews ?? 0),
      img: x.thumbnail,
      shipDays: "۱۰–۱۴",
      cat: "skincare"
    }));
    return Response.json(items);
  }
};
```

گزینه‌های جایگزین برای گرفتن داده: Rainforest API (آمازون)، Keepa (تاریخ قیمت)،
Awin/Impact (فید رسمی برندها)، یا اسکرپینگ قانونی با احترام به `robots.txt` و نرخ درخواست.
**هشدار حقوقی:** پیش از انتشار تجاری، شرایط استفادهٔ هر فروشگاه و قوانین نمایش قیمت را
با مشاور بررسی کنید؛ نمایش «قیمت تقریبی» و «زمان تقریبی» الزامی است.

### ۶٫۳ نرخ ارز

`ROSEA.rate` در `js/data.js` نرخ ثابت و تاریخ‌دار است تا قیمت‌ها ناگهان تغییر نکنند. برای
نرخ روز، همان Worker می‌تواند `GET /api/rates` بدهد و در ابتدا `ROSEA.rate` را بازنویسی
کند. همیشه تاریخ نرخ را نشان دهید (همین حالا در صفحه دیده می‌شود).

## ۷. داده و ساختار فایل

```text
rosea/
├── index.html, shop.html, product.html, global-search.html, cart.html, guide.html
├── css/rosea.css          # تمام استایل (توکن‌ها در :root)
├── js/
│   ├── data.js            # محصولات، دسته‌ها، منابع خارجی، ایندکس جهانی، نرخ ارز
│   ├── app.js             # سبد، کشوها، جست‌وجوی سریع، کارت محصول، توست، آکاردئون
│   ├── shop.js            # فیلتر/مرتب‌سازی/چیپ‌ها/بارگذاری تدریجی + همگام با URL
│   ├── product.js         # رندر PDP، گالری، مقایسهٔ قیمت، سبد
│   ├── global-search.js   # جست‌وجوی جهانی، تبدیل ارز، پیست لینک، سفارش واردات
│   └── cart.js            # سبد صفحه، ارسال، اعتبارسنجی، سفارش نمونه
├── src/                   # قطعه‌های منبع صفحه‌ها + هدر/فوتر مشترک
│   ├── partials.py        # HEADER / FOOTER
│   └── *.body.html        # محتوای <main> هر صفحه
├── tools/build-pages.py   # مونتاژ شش فایل HTML
└── assets/
    ├── img/               # ۱۰ تصویر تولیدشده (هیرو، ۶ دسته، ۲ محصول، بسته‌بندی)
    ├── fonts/             # ۷ فایل woff2
    └── favicon.svg
```

**ساخت مجدد صفحه‌ها:**

```bash
cd rosea
python3 tools/build-pages.py     # فقط شش فایل HTML را بازنویسی می‌کند
```

> اگر HTML را دستی ویرایش می‌کنید، تغییر را در `src/*.body.html` هم بگذارید، وگرنه
> ساخت بعدی آن را از دست می‌دهد.

**کلیدهای ذخیره‌سازی محلی:** `rosea-cart-v1` (سبد)، `rosea-favs-v1` (علاقه‌مندی)،
`rosea-last-order` (آخرین سفارش)، `rosea-import-requests` (استعلام لینک).

## ۸. کارایی، سئو و دسترس‌پذیری

- بدون فریم‌ورک، بدون CDN، بدون فونت گوگل؛ کل صفحه‌ها با HTML/CSS/JS خالص.
- تصاویر با ابعاد مشخص (`width`/`height`) و `loading="lazy"` جز هیرو (`fetchpriority=high`).
- CSS تک‌فایل با متغیر؛ JS به شش فایل کوچک تقسیم شده و فقط در صفحهٔ مربوط بار می‌شود.
- هر صفحه `title`، `description`، `og:*` و مسیر breadcrumb دارد؛ ساختار `h1 → h2` رعایت شده.
- حالت `prefers-reduced-motion`، حالت چاپ، فوکوس مرئی و `aria-*` برای کشو/آکاردئون/نتایج.
- RTL با logical properties (`inset-inline`, `padding-inline`) و LTR آماده در CSS.

## ۹. محدودیت‌های نسخهٔ نمایشی

1. **داده‌ها نمونه‌اند**: نام برندها، محصولات و قیمت‌ها ساختگی‌اند تا مسئلهٔ علامت تجاری ایجاد نشود.
2. **تصاویر با هوش مصنوعی تولید شده‌اند** (۱۰ تصویر). برای انتشار واقعی، عکاسی محصول با
   همان زبان بصری (رز/فیروزه، نور نرم، سایهٔ بلند) جایگزین شود.
3. **بدون بک‌اند**: سبد و سفارش در `localStorage` می‌مانند؛ درگاه پرداخت و پیامک متصل نیست.
4. **جست‌وجوی جهانی روی ایندکس محلی** است؛ برای خواندن زندهٔ لینک، بخش ۶٫۲ را پیاده کنید.
5. فرم‌ها اعتبارسنجی سمت کاربر دارند و اطلاعاتی ارسال نمی‌شود.
